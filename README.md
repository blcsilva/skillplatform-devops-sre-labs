# Skill Platform - Laboratorios DevOps e SRE

Repositorio de laboratorios praticos para a plataforma Skill Platform.

Cada pasta em `labs/` corresponde a uma aula da plataforma e contem:

- `README.md` com instrucao do aluno.
- `compose.yaml` para subir o ambiente.
- `Dockerfile` quando necessario.
- `workspace/` com dados ficticios e area de evidencias.
- `scripts/validate.sh` para verificacoes simples.

Os laboratorios nao possuem secrets e nao dependem de credenciais reais.
