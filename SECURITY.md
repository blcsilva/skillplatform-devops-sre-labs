# Seguranca dos laboratorios

Estes laboratorios usam apenas dados ficticios e imagens publicas.

Nao publique senhas, tokens, chaves privadas, arquivos `.env` ou credenciais reais.

Antes de abrir pull request ou publicar alteracoes, revise:

- URLs que possam conter tokens.
- Arquivos `.pem`, `.key`, `.pfx`, `.env` ou dumps reais.
- Logs copiados de ambientes corporativos.
- Dados pessoais, IPs internos sensiveis ou nomes de clientes.
